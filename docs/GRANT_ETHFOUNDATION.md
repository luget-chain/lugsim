## 1. Project Summary
LUGET is a dual-domain Layer-1 blockchain that separates sound money (UTXO Core) from programmability (Object VM) via a BLS-secured firewalled bridge. 66 tests. Zero failures. Mathematically proven invariants. No premine. No VCs. Built from Kenya.

## 2. Problem
Existing blockchains merge monetary sovereignty and programmability into a single fault domain. Bridges introduce custodial risk exploited for billions.

## 3. Solution
Domain separation at the consensus layer. Core: Bitcoin-style UTXO. VM: Object-centric with type abilities that prevent vulnerabilities at runtime. Bridge: Mandatory epoch delay with BLS threshold attestation. Emergency unilateral close.
