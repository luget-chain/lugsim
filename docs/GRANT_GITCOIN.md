## One-Liner

## Description
LUGET is a Layer-1 blockchain that separates its monetary base (UTXO Core) from its application layer (Object VM) at the protocol level. A firewalled bridge with BLS threshold signatures connects them. A failure in one domain cannot contaminate the other.

The Phase 0 simulator is complete: 66 Rust tests, Ed25519/Blake3/BLS cryptography, multi-node BFT consensus, CLI wallet, block explorer, and formal mathematical proofs of all three bridge invariants.
